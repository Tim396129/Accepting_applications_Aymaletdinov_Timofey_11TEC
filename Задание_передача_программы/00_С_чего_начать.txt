С ЧЕГО НАЧАТЬ

1. Полностью распакуйте Задание_передача_программы.zip.
2. Откройте 01_Презентация_Приём_заявок_Tkinter.pptx — здесь теория и 126 наглядных шагов.
3. Для работы рядом с VS Code откройте 03_Каждое_действие_в_картинках.pdf. Нажмите нужный раздел оглавления; номер вверху — номер действия.
4. Выполняйте действия по порядку: жёлтая рамка и стрелка показывают место нажатия; справа указаны действие и результат.
5. В VS Code откройте Программа_приёма_заявок. Нужен Python 3 с Tkinter. Запуск: Windows — python app.py или py app.py; Mac/Linux — python3 app.py.
6. Источники для заполнения: окно программы, README.md, ТРЕБОВАНИЯ.txt, ЗАПРОС_ЗАКАЗЧИКА.txt и УСЛОВИЯ_ЗАДАНИЯ.txt.
7. Пустые шаблоны — в Шаблоны. Рабочие документы 00–08 создавайте в Передача_программы внутри проекта. Подробные пояснения — в инструкции 02.
8. Исходная версия — 0.3.0; исправленная — После_исправления/app.py версии 0.3.1. Сначала зарегистрируйте дефект исходной, затем проверьте исправление.

Изображения в презентации и PDF — учебные схемы интерфейса. Они созданы без захвата рабочего стола. Оформление и язык меню могут отличаться; имена файлов и логика соответствуют комплекту. Факты записывайте после своего запуска.

Готовые заполненные формы в архив не включены.

В Комплект_0_3_1 создавайте собственный README.md из Шаблоны/README_для_комплекта.md. Исходный README описывает учебный проект и для получателя не подходит.
